# AI 應用：我的小房子

這次作業是在 500 × 400 的畫布上畫出小房子的風景。我使用 AI 協助產生 Java Swing 繪圖程式，包含天空、草地、太陽、雲朵、房屋、門窗和簽名。題目有指定要使用的繪圖方法，但沒有提供各個物件的確切位置、尺寸和 RGB 色碼，這些數值是由 AI 參考圖片後設定的。

AI 協助的部分是安排物件的位置。例如太陽的直徑設為 70、窗戶的大小設為 50 × 50，這些都是 AI 提供的數值。天空與草地的高度各為 200，則是依照畫布高度 400 和上下各一半的要求計算出來的。這也讓這份程式的草地比例與範例圖片不同，因為程式採用的是文字題目的要求。

繪圖方法方面，房屋和窗戶使用 `fillRect` 填色，再用 `drawRect` 畫外框；屋頂依照題目限制，只用三條 `drawLine` 組成三角形。填滿圖形和只畫外框是不同的操作，繪製的順序也會影響結果。例如窗戶的十字線要在白色底色之後畫，才不會被蓋住。

太陽光芒的計算是這份程式中比較需要仔細閱讀的部分。AI 採用題目提示的迴圈搭配 `Math.cos` 和 `Math.sin`，將 8 條光芒平均分配在圓周，每條相隔 45 度。光芒起點和終點距離圓心多遠，則是由 AI 設定。閱讀這段程式時，需要分清楚圓心位置、角度和距離各自的作用，不能只看最後畫出了幾條線。

另外，雲朵是由三個重疊的白色橢圓組成，窗戶則透過迴圈重複繪製相同形狀。這些部分呈現了如何用簡單圖形組合出完整畫面。如果之後要移動房屋，屋頂、門和窗戶的座標也需要一起調整，否則物件之間的位置就會對不上。

這次 AI 的協助包含程式產生、數值配置和視窗設定。AI 提供了可供參考的實作，但程式通過編譯不代表我已經理解每一段內容。後續練習可以從自己修改房屋的位置、窗戶的大小或光芒的長度開始，先預想畫面會如何改變，再執行確認，藉此練習題目要求的座標思考。
